Features

  • Structure-Aware Output: Generates a clean `` diagram so the AI understands your project's layout before reading the code.
  • 100% Private: All files are processed locally in your browser. Your code never touches a server.
  • Interactive File Tree: Easily expand, collapse, and select the exact files and folders you need.
  • Smart File Filtering: Automatically respects common ignore patterns (like .git and node_modules), saving you time.
  • Instant Token Analysis: Provides a real-time token count and a human-readable pronunciation to help you manage context window limits.

How to Use

  1. Open the App: The application is ready to use as soon as the page loads.
  2. Select Your Folder: Click the "Select Directory" button to choose the project folder you want to analyze.
  3. Refine Your Selection: Use the checkboxes in the sidebar to include or exclude specific files and directories from your prompt.
  4. Copy or Download: Use the action buttons in the top-right of the editor to copy the complete prompt to your clipboard or download the generated file.
